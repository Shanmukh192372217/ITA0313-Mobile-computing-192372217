MOBILE COMPUTING - ASSIGNMENT 5 (CO5)

The assignment separates Part A (design / architectural pseudocode) from Part B
(implementation and computational investigation). The assignment explicitly says
Part A pseudocode must be language-independent and programming-language code
will not be accepted as pseudocode.

Therefore this ZIP provides separate runnable Python simulations for the four
Part B implementation tasks:

- Task B1: Background work instrumentation and scheduling
- Task B2: Adversarial background workloads
- Task B3: Exact vs adaptive UI optimisation
- Task B4: Multimedia encoding heuristic

Each program is independent and uses only Python's standard library.

How to run:
1. Extract the ZIP.
2. Open Programiz Online Python Compiler.
3. Copy one Task_B*.py file into Programiz and click Run.
4. Run each task separately.

Output_Images contains illustrative terminal-style reference outputs generated
from these programs. They are not screenshots captured from Programiz.

Important:
These are educational prototypes with simplified assumptions, not production Android
WorkManager implementations, real camera encoders, or device performance benchmarks.
State the assumptions in your report and interpret the results. Complete Part A using
language-independent pseudocode / architecture as required by the assignment.
