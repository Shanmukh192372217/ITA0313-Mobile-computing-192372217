MOBILE COMPUTING - ASSIGNMENT 2 (CO2)

This ZIP contains seven independent Python programs, one for each question (Q1-Q7),
and seven illustrative terminal-style reference output images.

How to use:
1. Extract the ZIP.
2. Open Programiz Online Python Compiler.
3. Open one Task_*.py file, copy its complete code, paste into Programiz, and click Run.
4. Run each task separately.

All programs use Python's standard library only.
These are educational prototypes/simulations with stated assumptions, not full GSM or
RF standards simulators. Explain the assumptions and defend your results in the report.
